ทางเข้า
เปิด index.html แล้วกด “อะไหล่นำเข้า” ในเมนูหลัก หรือการ์ด TunersGate บนหน้าแรก
ไฟล์เดี่ยว outputs/Carwise.html และ outputs/github-pages/index.html รวมโค้ดและภาพประกอบไว้แล้ว
ไม่ต้องใช้ GitHub หรือเชื่อมต่ออินเทอร์เน็ตสำหรับขั้นตอนสาธิต

สิ่งที่ใช้งานได้
- แค็ตตาล็อก 8 รายการตัวอย่าง ครอบคลุม 4 ยี่ห้อรถและ 4 หมวดอะไหล่
- กรองยี่ห้อ รุ่น หมวด และค้นหาชื่อ/รหัสสินค้า
- หน้ารายละเอียดภาษาไทยพร้อมน้ำหนัก ขนาดพัสดุ สต็อก และรุ่นรถตัวอย่าง
- เพิ่ม/ลด/นำสินค้าออกจากตะกร้า ป้องกันจำนวนเกินสต็อกและสินค้าไม่มีสต็อก
- ปรับเรทตัวอย่าง เลือกขนส่งอากาศ/เรือ และกรอกยอดภาษี/ค่าธรรมเนียมสมมติ
- แยกค่าสินค้า ค่าขนส่ง ภาษีที่กรอก และยอดรวมประมาณการ
- น้ำหนักคิดค่าขนส่งใช้ค่ามากกว่าระหว่างน้ำหนักจริงและปริมาตร / 5000
  ค่าตั้งต้นและอัตราต่อกิโลกรัมเป็นสมมติฐานสำหรับสาธิตเท่านั้น
- สร้างคำสั่งซื้อจำลองโดยไม่มีการเรียกเก็บเงิน
- ติดตาม 5 ขั้นตอน โดยกดจำลองสถานะถัดไปได้
- คำสั่งซื้อเก็บยอดประมาณการ ณ เวลาสร้าง การเปลี่ยนเรทภายหลังไม่กระทบยอดเก่า
- ดาวน์โหลดสรุปคำสั่งซื้อแบบข้อความ
- ตะกร้า ค่าคำนวณ และคำสั่งซื้อเก็บใน localStorage แยกจากเคสคัดกรองรถ

ขอบเขต
สินค้า รหัส รุ่นรองรับ สต็อก ราคา และวันขนส่งเป็นข้อมูลสมมติทั้งหมด
ภาพสินค้าวาดเป็น SVG ประกอบ ไม่ใช่ภาพสินค้าจริงจากผู้ขาย
ไม่มีผู้ขายหรือระบบคลังสินค้าจริง ไม่มีอัตราแลกเปลี่ยนสด ไม่มีการประเมินภาษีตามกฎหมาย
ไม่มีการชำระเงินจริง การจองขนส่ง หรือข้อมูลติดตามจากบริษัทขนส่ง
ก่อนซื้อจริงต้องให้อู่ยืนยันรุ่น/รหัสอะไหล่ และขอราคาสุทธิจากผู้ให้บริการ
ข้อมูลเก็บเฉพาะเบราว์เซอร์และที่อยู่เว็บที่เปิด ล้างข้อมูลเบราว์เซอร์แล้วประวัติจะหาย

ไฟล์ใหม่
tuners-engine.js — ข้อมูลตัวอย่าง กฎตะกร้า สูตรประมาณการและสถานะคำสั่งซื้อ
tuners-ui.js — หน้าจอค้นหา รายละเอียด ตะกร้า คำสั่งซื้อและติดตาม
tuners.css — รูปแบบหมวดใหม่ที่ใช้สีและองค์ประกอบร่วมกับ Carwise

การตรวจสอบ
ชุดทดสอบรวม 25/25 ผ่าน: 17 ข้อเดิม + 8 ข้อสำหรับหมวดอะไหล่
ตรวจผ่านเบราว์เซอร์: กรองยี่ห้อ ค้นหารหัส เปิดรายละเอียด เพิ่มลงตะกร้า
เพิ่มจำนวนโดยคงชื่อผู้รับ ป้องกันสร้างคำสั่งซื้อจากราคาที่ยังไม่คำนวณใหม่
ปรับขนส่ง สร้างคำสั่งซื้อ เลื่อนสถานะ และรีเฟรชแล้วยังพบข้อมูล
ตรวจหน้าค้นหาและติดตามที่ความกว้าง 390px: ไม่มีเนื้อหาดันออกนอกจอ
ตรวจการทำงานเดิมของ Goal ผ่านชุดทดสอบ และตรวจไฟล์เดี่ยวว่า JavaScript ทั้ง 5 ชุดถูกต้อง
การดาวน์โหลดลงดิสก์จริงและการพิมพ์ไม่ได้ทดสอบซ้ำในรอบนี้
